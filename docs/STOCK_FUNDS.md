# 个股主力资金接口与 K 线对齐

已检查本地 `app/build/backend-contract/marketdata/api.py`：当前后端提供日线和龙虎榜，尚未实现个股主力资金时间序列。下述接口是本次前端预留的可选契约，不能据此认定生产服务已提供数据。

## 可选接口

`GET /v1/cn/stocks/{instrument_id}/flows?end=2026-09-30&limit=2000`

沿用行情服务的 Bearer 认证。`instrument_id` 必须是 `CN.stock.` 加 6 位股票代码。`end` 与日线请求截至日期一致，最多返回 2000 条，按交易日排序。示例：

```json
{
  "instrument_id": "CN.stock.688981",
  "currency": "CNY",
  "unit": "yuan",
  "scope": "main",
  "source": "provider/main-order-flow",
  "updated_at": "2026-10-01T00:00:00Z",
  "items": [
    {"trade_date": "2026-09-30", "inflow": null, "outflow": null, "net": -12500000.0}
  ]
}
```

`net` 为主力净流入，流出为负；`inflow`、`outflow` 为非负总额，缺失可为 null；两项俱全时应满足 `inflow - outflow = net`，允许金额舍入误差。`scope=main` 的实际订单分类由 `source` 对应供应商定义，后端需要保持整段序列口径一致。此数据不是持仓变化，也不是对未来涨跌的判断。

前端校验股票标识、来源、人民币元单位、主力统计口径、时间戳和日期范围；重复日期、非有限金额、净额缺失、混入其他股票或来源的记录会拒绝展示。不存在的日不补零；零净流入仅表示供应商确实返回了 0。

404 / 501 显示“个股主力资金接口待接入”；认证失败保留认证提示；其他失败显示资金区域错误。资金与日线并行读取，资金失败不会清空成功的 K 线。离开详情取消整个请求，未完成的资金请求一并取消。

## 显示与周期对齐

- 日 K 按交易日期匹配，不依赖数组位置。
- 周 K 使用周一开始的日历周，月 K 使用自然月，和价格 K 线分组一致。
- 周/月主力净额只有在该根 K 线包含的所有已取得日线日期均存在资金记录时才相加；缺少任意一天就显示未知。这里不推断日线接口未返回的历史或停牌日期。
- 若资金日期晚于行情截至日期，整段响应校验失败。多余的早期资金记录不会混入图表。
- 美股暂无对应主力统计口径，显示“当前仅支持 A 股个股主力资金”。
- 演示模式使用独立的“模拟个股主力资金”序列，覆盖同一组日线日期，未用成交量或板块资金推算真实个股资金。

该指标不会替代观察池原有的关联板块资金。真实资金能否展示取决于后端实现和供应商覆盖。
