# 第一版验收 · 2026-09-30

## 已验证

- Android debug APK 构建通过（minSdk 26 / targetSdk 35）。
- Windows 自带 JRE 的分发目录、MSI 安装包构建通过。
- MSI 已改为仅当前用户安装，静默安装返回 0，安装目录为 `%LOCALAPPDATA%\Gproject`，不需管理员权限。
- Windows 程序启动后进程正常，产生“观市 · Gproject”窗口；锁屏阻止实际桌面交互，未声称完成手动 UI 验收。
- 9 项自动测试通过：5 项指标/数字边界测试、2 项 API 合约测试、2 项 Compose 界面交互测试。
- 指标覆盖：单边上涨、单边下跌、平盘 RSI、中途缺失成交量、混合来源、乱序日期、历史不足、零量，量比基线不包含当天。
- API 使用模拟引擎验证 Bearer 头、查询参数、nullable 字段、401 错误提示；不是公网端到端联调。
- Compose 在 390×844 与 1240×1000 两种尺寸渲染；验证三页切换、主动进入演示、MA60 条件应用。渲染图片在 `app/build/previews`，精选图存入 `docs/screenshots`。
- 手机弹窗均线选项采用两行布局，避免窄屏文字折行。截图中的行情均为演示数据。

## 尚未验证或依赖后端

- 当前无 adb 设备，未做真机安装、旋转、后台恢复和触控体验验收。手机尺寸的 Compose 离屏测试不等同于 Android 真机测试。
- 公网 API 先前关闭，未在本次任务中重新开启；生产数据未完成端到端联调。
- 资金流、连板、金油主连、日韩及 A 股指数的生产数据依赖后端新增接口。本版展示接入状态，演示模式单独标识。
- 筛选仅为前 30 个已登记 A 股的按需扫描；策略仅在当前会话内保留。没有全市场后台筛选或通知服务。
- APK 为调试签名，MSI 未做发行签名；适合内部体验。

## 后续接口约定建议

资金流需要交易日期、分类来源、流入/流出/净流入、金额单位与采集时间；连板需要各交易规则下涨停判定、连续交易日和停牌处理；全球行情需要市场时区、币种、交易日期、延迟状态、主连换月规则。

这些字段必须来自后端核验数据。当前前端不会自行推断涨停、资金流或主连合约。
